# Decisiones

Registro de decisiones técnicas y de diseño (ADRs ligeros).

## Formato

Cada decisión sigue esta estructura:

```markdown
# Título corto y descriptivo

**Fecha**: YYYY-MM-DD
**Contexto**: ¿Por qué necesitábamos tomar esta decisión?
**Decisión**: ¿Qué elegimos?
**Alternativas consideradas**: ¿Qué otras opciones evaluamos?
**Consecuencias**: ¿Qué impacto tiene esta decisión?
```
