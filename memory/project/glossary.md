# Glosario

Términos específicos del negocio y del proyecto.

## Negocio

| Término | Definición |
|---------|------------|
| Mayorista | Cliente principal que compra al por mayor para reventa |
| Kert S.A.S | Fabricante colombiano de maletas, mochilas, riñoneras y accesorios |
| SKU | Unidad de mantenimiento de stock (código único de producto) |

## Técnico

| Término | Definición |
|---------|------------|
| App Router | Sistema de enrutamiento de Next.js basado en el directorio `app/` |
| shadcn/ui | Colección de componentes React reutilizables, no es una librería instalable sino que se copian al proyecto |
| Tailwind v4 | Última versión de Tailwind CSS con nuevas características como `@theme` |

## Diseño

| Término | Definición |
|---------|------------|
| Deep Azul | `#0C0844` — color primario de marca |
| Bright Amarillo | `#FFCF00` — color secundario de CTA |
| Coral | `#ff5a5f` — color terciario de acento |
