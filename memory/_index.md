## Stack

- **Framework**: Next.js 16 + React 19
- **Estilos**: Tailwind CSS v4 + shadcn/ui (New York)
- **Animaciones**: Framer Motion
- **Fuente**: Roboto (Google Fonts)
- **Colores**: Azul `#0C0844`, Amarillo `#FFCF00`, Coral `#ff5a5f`
